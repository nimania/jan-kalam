https://nimania.github.io/jan-kalam/

رابط سایت از snapshot تاریخی مخزن پندار در commit `e2f7996080` (۳ اکتبر ۲۰۲۶) بازیابی شده است. داده‌های قابل‌نمایش در فایل فشردهٔ `data/snapshot.json.gz` داخل همین مخزن نگهداری می‌شوند و سایت هنگام اجرا به پندار درخواست نمی‌فرستد.
